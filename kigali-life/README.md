# Kigali Life

A mobile-first browser city-life simulator MVP inspired by the *city-as-a-platform* pattern. This implementation is an original project, not a copy of Lagos Life assets or code.

## MVP
- Schematic Kigali map with the three official districts: Gasabo, Nyarugenge, Kicukiro.
- Clickable locations: Kacyiru, Kigali CBD, Nyamirambo, Kicukiro Centre, Kimironko.
- Character setup with life paths.
- RWF economy, energy and reputation.
- Jobs, food, home/rest, moto transport and social actions.
- Responsive single-file browser build with no backend dependency.

## Geography note
The game map is explicitly **schematic / not to scale**. District structure is grounded in City of Kigali public planning information. Replace the schematic layer with licensed/approved GIS geometry before claiming street-level geographic accuracy.
